From private scalar to public point

Explore elliptic-curve scalar multiplication on a deliberately tiny finite-field curve. Change the scalar or base point, inspect each addition, and observe the small subgroup’s coordinate statistics.

Educational toy only. This curve has a tiny finite field and offers no real security. It is not Ethereum’s secp256k1 and must never be used to protect funds or secrets.

1. Set the experiment

E: y² ≡ x³ + 7 (mod 17)

The curve is fixed; choose a valid point on it as the base point G. The default matches the assignment.

Toy public key Q = kG
(5, 8)

For the default G=(1,5), the example k=6 gives Q=(5,8).

What each step means

Scalar multiplication repeatedly adds the same point: 2G=G+G, 3G=2G+G, and so on. The point-at-infinity (∞) acts as the identity element. Arithmetic, including division, is performed modulo 17.

Q = kG = G + G + ··· + G

Finite-field point addition

For distinct points, λ=(y₂−y₁)/(x₂−x₁) mod 17. For doubling, λ=3x₁²/(2y₁) mod 17. Then x₃=λ²−x₁−x₂ and y₃=λ(x₁−x₃)−y₁, all modulo 17. Modular division means multiplying by a modular inverse.

5. What the experiment does—and does not—show

  • Determinism: the same G and k always produce the same Q.
  • Finite cyclic subgroup: kG repeats with the order of G; this toy base point has order 9, so it is easy to search by trying every possibility.
  • Not a hash: scalar multiplication outputs a curve point and preserves group structure. It is not designed to satisfy a hash function’s fixed-length digest and collision-resistance goals.
  • “Avalanche” caution: changing k to k+1 gives (k+1)G=kG+G, not an unrelated output by definition. Tiny coordinate frequencies or bit counts from this toy example cannot establish cryptographic security.
